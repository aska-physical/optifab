## Links

Link types:

- `builds_on`: The downstream work uses results, certificates or code of the upstream work, and the use was traced. Lineage.
- `stated`: The downstream repository says it builds on the upstream one. No specific value was traced here. Lineage.
- `direction`: The downstream work follows a question or direction of the upstream work, which has no results. Lineage.
- `consumes`: The downstream work reads a specific value or file of the upstream work. Lineage.
- `governs`: The upstream work sets rules or a scale that the downstream work follows. Not lineage.
- `mentions`: One names the other in text. No data flows. Not lineage.
- `indexes`: A hub lists the repository. Not lineage.
- `checked_unrelated`: One specific proposed link that was checked and found not to hold. Kept so it is not proposed again.
